How To Read It

  • The calculation uses the running closing peak across the full local index archive, even when the visible chart window starts later.
  • A falling line means the index is recovering toward its peak; a rising line means the drawdown is deepening. Intraday highs and reinvested dividends are excluded.
  • Actual index history preserves the membership changes reflected in the index. This differs from the current-member reconstruction used on breadth pages.
