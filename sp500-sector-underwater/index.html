How To Read It

  • This board shows how far each sector still sits below its own prior peak.
  • Shallow drawdowns that recover quickly usually confirm strong leadership; deep drawdowns signal unfinished damage.
  • It is especially useful when the main index looks fine but several sectors are still far from healed.
